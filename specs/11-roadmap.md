# 11. Roadmap and backlog

## 1. Подход

Только frontend. Работаем от статических JSON и моков, без backend/CMS/админки. Каждый этап заканчивается сборкой на staging и приёмкой. Backend/инфраструктура и контент — внешние зависимости.

## 2. Этапы

### Этап 0. Подготовка (1 неделя)

- Утвердить Nuxt 3, PrimeVue, Pagefind, структуру JSON.
- Получить SVG-логотип в цветной и монохромной версиях.
- Согласовать `schemas/content.ts` с поставщиками контента.
- Согласовать список внешних сервисов (ссылки/iframe).
- Подготовить репозиторий, CI, staging на Nginx.

**Выход:** решения зафиксированы, есть доступы и тестовые данные.

### Этап 1. Каркас и дизайн-система (3–4 недели)

- Nuxt 3, TypeScript, ESLint/Prettier, Vitest.
- Подготовка SVG-логотипа и правил использования.
- PrimeVue preset, CSS-токены, базовые компоненты.
- App shell: шапка, футер, навигация, language switcher, breadcrumbs, 404.
- i18n RU/EN.
- Валидация JSON (Zod) и mock-данные.
- Скрипты конвертации текущих данных в JSON.
- SSG-сборка и деплой на staging.

**Выход:** можно собрать и открыть статический сайт с mock-страницами.

### Этап 2. Ядро разделов (5–7 недель)

- Главная.
- Университет: о вузе, структура, сотрудники, документы, контакты.
- Поступление: уровни, правила, сроки, стоимость, FAQ.
- Образование: каталог программ, карточка, учебный процесс, библиотека.
- Конвертация приоритетных данных в JSON и ручная проверка.
- Навигация и крошки для всех разделов.
- Формы-моки.

**Выход:** MVP основных страниц на JSON.

### Этап 3. Остальные разделы (4–6 недель)

- Наука: направления, лаборатории, аспирантура, диссоветы, конференции, журналы.
- Студенческая жизнь: события, культура, спорт, общежитие, стипендии, поддержка, ОВЗ.
- Международное сотрудничество.
- Новости и архив.
- Музей.
- EN-переводы и EN-зеркало.

**Выход:** все 8 разделов реализованы.

### Этап 4. Поиск, SEO и редиректы (2–3 недели)

- Pagefind, поисковый UI, фасеты, RU/EN.
- Meta, canonical, OG, JSON-LD, hreflang.
- Sitemap/robots.
- `redirects.json`/`gone.json` из `url-map.csv` + адаптер под хостинг.
- Проверка 301 на staging (Nginx доступен).
- Sveden-шаблон и валидация microdata.

**Выход:** сайт готов к приёмке.

### Этап 5. Доступность и производительность (2 недели)

- ГОСТ Р 52872-2019, WCAG 2.1 AA.
- Версия для слабовидящих.
- Lighthouse/axe, бюджеты.
- Оптимизация изображений и шрифтов.
- Кроссбраузерность.

**Выход:** метрики и доступность в норме.

### Этап 6. Запуск и стабилизация (1–2 недели)

- Финальная сборка, передача `redirects.json`/`nginx.conf` инфраструктуре.
- Production deploy.
- Мониторинг 404/500 на Nginx.
- Исправление ссылок и переводов.
- Ретроспектива.

**Выход:** стабильный статический сайт на Nginx.

## 7. Риски

| Риск | Мера |
|---|---|
| Нет согласованного JSON | `schemas/content.ts` + mock, валидация, скрипты конвертации |
| Конвертация текущих данных | Приоритет MVP, ручная проверка, тесты |
| Нет полного EN-контента | Машинный черновик + редактор, приоритет разделов |
| Нет полного брендбука | SVG есть; токены и UI-кит вокруг логотипа |
| Sveden-разметка | Отдельный шаблон, тесты, поставщик данных |
| Nginx не применяет редиректы | `redirects.json` + `nginx.conf`/`map` + чек-лист инфраструктуре |
| Формы-моки путают пользователей | Явная плашка «Демо-режим» |
| PrimeVue-вес | Импорт только нужных компонентов, бюджеты |
| Нет Nginx-хостинга | Спецификация не привязана, SSG переносим |

## 8. Метрики этапов

- Этап 1: Lighthouse ≥ 90 на shell, 0 critical axe.
- Этап 2: все пункты меню 200, основные страницы на JSON.
- Этап 3: все разделы IA, EN-зеркало готовых разделов.
- Этап 4: Pagefind работает, `redirects.json` валиден, sitemap/robots.
- Этап 5: LCP ≤ 2.5s, INP ≤ 200ms, CLS ≤ 0.1, ГОСТ проверен.
- Этап 6: 404 ≤ 1%, статика на Nginx, редиректы применяются Nginx.
