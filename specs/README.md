# Спецификации frontend нового сайта ГМУ им. адм. Ф.Ф. Ушакова

Статус: черновик v0.2
Основа: текущий сайт `aumsu.ru` (382 живых страницы, 414 проверенных URL), `Reference/url-map.csv`, `СборДанных/data/extracted/`.

## Что делаем

Только frontend публичного сайта. Backend, CMS, хранение данных, админка, интеграции и юридические согласования — вне зоны ответственности команды. Контент приходит в виде статических JSON/файлов, сайт собирается в SSG и публикуется на Nginx.

## Зафиксированные решения

| Вопрос | Решение |
|---|---|
| Framework | Nuxt 3 (Vue 3 + TypeScript) |
| Рендеринг | SSG/SSR, основной вариант — SSG + Nginx |
| Данные | Статические JSON/файлы, без API; JSON готовит frontend из текущих данных |
| Языки | Русский + английский, полное зеркало; EN-переводы делает frontend, внешнего приёмщика нет |
| UI | PrimeVue + собственные обёртки/токены |
| Поиск | Pagefind по статическому индексу |
| Формы | Моки без реальной отправки |
| Хостинг | Nginx: статика + `nginx.conf`/`map` |
| Редиректы | Frontend генерирует `redirects.json`, 301 выполняет Nginx |
| Внешние сервисы | Ссылки; embed: расписание, виртуальный тур, карта, видео |
| Бренд | Есть SVG-логотип; систему создаём вокруг него |
| Доступность | WCAG 2.1 AA + ГОСТ Р 52872-2019 + режим для слабовидящих |
| Админка | Не нужна |

## Границы

Входит:

- Публичный сайт: все разделы, страницы, навигация, поиск, i18n.
- Конвертация текущих данных в статические JSON.
- EN-переводы.
- Работа с SVG-логотипом.
- Вёрстка и компоненты.
- SSG-сборка.
- SEO: meta, canonical, sitemap, JSON-LD, `redirects.json`.
- Доступность и версия для слабовидящих.
- Моки форм.
- UI поиска на Pagefind.
- Генерация карты редиректов для Nginx.

Не входит:

- Backend, база данных, API, CMS, админка.
- Хранение и загрузка файлов.
- Реальная отправка форм.
- Настройка Nginx и 301 на проде.
- Юридическая проверка sveden.
- Наполнение новым контентом (кроме конвертации текущего и EN-перевода).
- Интеграции с 1С/ЛК, кроме ссылок/embed.

## Соглашения

- `MUST` / `ДОЛЖЕН` — обязательное требование.
- `SHOULD` / `СЛЕДУЕТ` — рекомендуемое, отклонение обосновывается.
- `MAY` / `МОЖЕТ` — опционально.
- Тексты интерфейса — на русском и английском; код и имена полей — на английском.
- Даты в данных — ISO 8601; отображение — Europe/Moscow.
- Идентификаторы — строки; человекочитаемый ключ — `slug`.

## Решённые вопросы

1. Формат JSON не согласован. Контракт задаёт frontend: `specs/schemas/content.ts` + Zod-схемы. JSON готовит frontend из текущих данных.
2. Есть SVG-логотип.
3. EN-переводы делает frontend; отдельного приёмщика/редактора EN нет.
4. Embed: расписание, виртуальный тур, карта, видео. URL подставляются позже.
5. Версия для слабовидящих — режим темы с сохранением настроек.
6. Хостинг — Nginx, редиректы через `nginx.conf`/`map`.

## Открытые вопросы

1. Есть ли правила использования SVG-логотипа (монохромная версия, охранное поле, минимальные размеры)? Если нет, зафиксируем в дизайн-системе.
2. EN-переводы не проходят внешнюю редактуру. Если качество станет критичным, нужно решение: скрыть EN или добавить редактора.
3. Точные URL embed-сервисов подставляются позже в `external-services.json`.
