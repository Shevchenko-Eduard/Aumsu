# 00. Product overview

## 1. Контекст

Текущий сайт — Joomla с шаблоном `beez_20` и XHTML 1.0 Transitional: 382 живых HTML-страницы, 32 битых URL, 59 групп дублей (154 URL), 148 адресов с `/8-glavnaya-stranitsa/`, 56 страниц кафедр/факультетов/управлений и 3627 ссылок на документы. Навигация смешивает разделы, обязательный `sveden`, внешние сервисы и устаревшие страницы.

Переделываем только frontend: Nuxt 3 + TypeScript + Vue 3, статические JSON/файлы как источник данных, SSG-сборка и публикация на Nginx. Backend, CMS, админка, хранение данных и реальная отправка форм — вне зоны команды.

## 2. Цели

1. Дать абитуриенту один понятный путь от интереса до подачи документов.
2. Дать студенту, сотруднику и выпускнику быстрый доступ к нужной информации и сервисам.
3. Собрать понятную структуру: 8 разделов, не более 2–3 уровней в навигации.
4. Убрать дубли, мёртвые ссылки и устаревшие страницы из основного контура.
5. Обеспечить SEO на статической сборке: SSR/SSG, meta, canonical, sitemap, JSON-LD.
6. Обеспечить доступность: WCAG 2.1 AA, ГОСТ Р 52872-2019, версия для слабовидящих.
7. Сделать полное EN-зеркало сайта.
8. Сохранить обязательный раздел `sveden` и его разметку.
9. Сделать frontend быстрым, предсказуемым и поддерживаемым без backend.
10. Конвертировать текущий контент в статические JSON и подготовить EN-зеркало.

## 3. Не цели

- Backend, API, база данных, CMS, админка.
- Реальная отправка форм, интеграция с почтой/CRM.
- Хранение файлов и документов.
- Настройка Nginx, DNS и 301 на проде.
- Наполнение новым контентом, кроме конвертации текущего и EN-перевода.
- Интеграции с 1С, ЛК, расписанием, кроме ссылок/embed.
- Юридическая проверка sveden и нормативных документов.
- Ребрендинг с нуля: есть логотип, вокруг него строим систему.

- Конвертация текущего контента в JSON-скрипты.

- Работа с существующим SVG-логотипом.

- Загрузка/хранение медиа.
- Реальная отправка форм.
- Настройка Nginx и 301 на проде.
- Наполнение новым контентом, кроме конвертации текущего и EN-перевода.
- Юридические согласования.

## 7. Ограничения

- **Данные.** Только статические JSON/файлы; frontend не ходит в API. JSON готовит frontend из текущих данных.
- **SSG.** Публичные страницы должны быть в HTML на первом запросе.
- **Формы.** Только моки; реальная отправка не входит.
- **Редиректы.** Frontend генерирует `redirects.json`; 301 выполняет Nginx.
- **Sveden.** URL и microdata сохраняются; данные приходят из JSON.
- **EN.** Полное зеркало; переводы делает frontend, внешней редактуры нет — риск качества фиксируем.
- **Доступность.** WCAG 2.1 AA, ГОСТ Р 52872-2019, версия для слабовидящих.
- **Бренд.** Есть SVG-логотип; палитру, типографику и компоненты создаём вокруг него.
- **Хостинг.** SSG-статика за Nginx; редиректы через `nginx.conf`/`map`. Node SSR не обязателен.
- **Embed.** Расписание, виртуальный тур, карта, видео. Остальные сервисы — ссылками.

## 8. Ключевые решения

1. Nuxt 3 + TypeScript + Vue 3.
2. SSG + Nginx; SSR как опция, но не требование.
3. Данные — статические JSON/файлы в репозитории. Формат не согласован, контракт задаёт `schemas/content.ts` + Zod; JSON готовит frontend из текущих данных.
4. PrimeVue как база UI + собственные обёртки и токены.
5. Pagefind для поиска.
6. RU + EN с полным зеркалом.
7. 8 разделов; `sveden` отдельно.
8. Один канонический URL на сущность; старые URL — 301 на Nginx.
9. Формы — моки.
10. Внешние сервисы — ссылки/embed.
11. Новый визуальный язык вокруг существующего SVG-логотипа.
12. EN-переводы делает frontend.
13. Embed: расписание, виртуальный тур, карта, видео.
14. Доступность и слабовидящие — обязательны.

## 9. Риски

| Риск | Вероятность | Влияние | Меры |
|---|---|---|---|
| Формат JSON не согласован | Высокая | Высокое | `schemas/content.ts` как контракт; Zod-валидация; frontend готовит JSON |
| Конвертация текущего контента | Высокая | Высокое | Скрипты, ручная проверка, приоритет MVP |
| EN-переводы ресурсоёмки | Высокая | Среднее | Глоссарий, машинный перевод, выборочная проверка внутри frontend |
| Нет полного брендбука | Средняя | Среднее | SVG-логотип есть; палитру и правила фиксируем в дизайн-системе |
| Нет полного EN-контента | Высокая | Среднее | Заглушки/скрытие непереведённых страниц, график переводов |
| Нет брендбука | Высокая | Среднее | Собрать токены и UI-кит вокруг логотипа, согласовать |
| Sveden-разметку сломают | Средняя | Высокое | Отдельный шаблон, тесты, JSON-структура |
| Редиректы не настроит Nginx | Средняя | Высокое | `redirects.json` + чек-лист для инфраструктуры |
| Внешние сервисы меняют URL | Средняя | Среднее | Центральный конфиг ссылок |
| Формы без backend | Высокая | Низкое | Явные моки и сообщение «демо» |
| Нет контента в срок | Высокая | Высокое | Заглушки, приоритет MVP |
