# 06. Design system

## 1. Принципы

1. Ясность важнее декора: пользователь быстро находит нужный раздел.
2. Единые компоненты и состояния во всех разделах.
3. Доступность по умолчанию: контраст, фокус, клавиатура, семантика.
4. Мобильный сценарий — приоритетный.
5. Контент важнее анимаций: движение только для обратной связи.
6. Новый бренд: есть только логотип, палитру, типографику и компоненты создаём вокруг него.

## 2. PrimeVue

- Базовая библиотека — PrimeVue.
- Все компоненты оборачиваются в собственные (`BaseButton`, `BaseTable` и т.д.), чтобы не зависеть от API PrimeVue напрямую.
- Тема — собственный preset на CSS-переменных.
- Не использовать дефолтный вид PrimeVue без кастомизации.
- Доступность PrimeVue проверяется axe и ручными тестами.

## 3. Входные данные бренда

Есть SVG-логотип. До старта дизайна нужны:

- цветная и монохромная версии SVG;
- правила охранного поля и минимальные размеры;
- favicon/иконка приложения;
- палитра: основной, акцент, нейтральные, семантические;
- типографика: 1–2 шрифта с лицензией;
- стиль фото/иллюстраций;
- тон коммуникации.

Правила использования:

- не перекрашивать и не добавлять эффекты;
- использовать прозрачный фон;
- предусмотреть монохромный вариант для тёмных фонов и слабовидящей темы;
- не растягивать непропорционально;
- соблюдать охранное поле.

До утверждения используем черновые токены из этого документа и помечаем их как `draft`.

## 4. Токены

### Цвета (черновая палитра до утверждения бренда)

| Токен | Значение | Использование |
|---|---|---|
| `--color-primary-900` | `#0B2A4A` | Заголовки, тёмный фон |
| `--color-primary-700` | `#123E6B` | Кнопки, ссылки |
| `--color-primary-500` | `#1D5C96` | Акценты |
| `--color-primary-100` | `#E6EFF7` | Фоны блоков |
| `--color-accent-600` | `#C58A1A` | CTA, выделения |
| `--color-accent-100` | `#FBF1DA` | Подсветка |
| `--color-text` | `#14202B` | Основной текст |
| `--color-text-muted` | `#5A6B7B` | Второстепенный |
| `--color-bg` | `#FFFFFF` | Фон |
| `--color-bg-subtle` | `#F5F7FA` | Секции, карточки |
| `--color-border` | `#D7DEE6` | Границы |
| `--color-success` | `#1F7A4D` | Успех |
| `--color-warning` | `#A15C00` | Предупреждение |
| `--color-danger` | `#B3261E` | Ошибка |
| `--color-info` | `#1D5C96` | Информация |
| `--color-focus` | `#F2B705` | Фокус-ринг |

Требование: контраст текста ≥ 4.5:1; крупного текста ≥ 3:1; проверка axe. Палитра — стартовая, финальные значения утверждаются после выбора направления бренда.

### Типографика

- Основной шрифт: утверждённый бренд-шрифт; fallback `system-ui, -apple-system, "Segoe UI", Roboto, Arial, sans-serif`.
- Заголовки: тот же шрифт, 600/700.
- Размеры (rem):
  - `h1`: 2.5 / 2.0 mobile
  - `h2`: 2.0 / 1.625
  - `h3`: 1.5 / 1.25
  - `h4`: 1.25
  - body: 1rem, line-height 1.6
  - small: 0.875rem
  - caption: 0.75rem
- Межстрочный интервал body — 1.6; заголовки — 1.2.
- Максимальная длина строки — 70–75 символов.

### Отступы и радиусы

- Шкала: 4, 8, 12, 16, 24, 32, 48, 64, 96 px.
- Радиусы: `4px` (мелкие), `8px` (карточки), `12px` (крупные), `999px` (pill).
- Тени: `0 1px 2px rgba(20,32,43,.08)`, `0 8px 24px rgba(20,32,43,.12)`.

### Сетка и брейкпоинты

| Брейкпоинт | Ширина |
|---|---|
| mobile | 0–639 |
| tablet | 640–1023 |
| desktop | 1024–1439 |
| wide | 1440+ |

- Контейнер: max-width 1280px, padding 16px mobile / 24px tablet / 32px desktop.
- 12-колоночная сетка на desktop, 4 — на mobile.
- Основной контент не шире 800px для текстовых страниц.

## 5. Компоненты и состояния

### Кнопки

- Варианты: primary, secondary, ghost, danger, link.
- Размеры: sm, md, lg.
- Состояния: default, hover, focus-visible, active, disabled, loading.
- Иконочная кнопка обязана иметь `aria-label`.

### Ссылки

- В тексте — подчёркивание или явный цвет, не только цвет.
- Внешние — иконка и `target="_blank"` + `rel="noopener noreferrer"`.
- Не использовать «здесь» и «подробнее» без контекста.

### Карточки

- Заголовок, краткое описание, метаданные, действие.
- Вся карточка кликабельна, но внутри могут быть отдельные ссылки; не вкладывать интерактив в интерактив.
- Фокус-ринг на карточке.

### Навигация

- Desktop: горизонтальное меню, выпадающие панели не более 2 уровней.
- Mobile: drawer, крупные touch-targets ≥ 44px.
- Активный пункт: цвет + подчёркивание, не только цвет.
- Skip link.

### Таблицы

- Заголовки `th` с `scope`.
- Горизонтальный скролл на мобильных.
- Не использовать таблицы для вёрстки.
- Для sveden — сохранять структуру и microdata.

### Формы

- Label всегда видим (кроме поиска).
- Ошибка рядом с полем + `aria-invalid`.
- Обязательные поля помечены.
- Подсказки и ограничения — до ввода.
- Кнопка отправки с loading.

### Уведомления

- Inline alert для ошибок формы.
- Toast для кратких успехов, но не для критичных ошибок.
- `role="status"` / `aria-live="polite"`.

## 6. Шаблоны

### Главная

1. Шапка с быстрыми входами.
2. Hero: название, короткое позиционирование, CTA «Поступить» и «Программы».
3. Быстрые ссылки по аудиториям.
4. Новости (3–6 карточек).
5. Ключевые цифры/направления.
6. Популярные программы.
7. События.
8. Блок «Университет» с картой/контактами.
9. Футер.

### Landing раздела

1. H1 + краткое описание.
2. Карточки подразделов.
3. Быстрые ссылки/документы.
4. Контактный блок.

### Карточка сущности

1. H1, метаданные.
2. Основной контент.
3. Боковая панель: контакты, руководитель, документы, связанные программы.
4. Хлебные крошки.

### Каталог

1. H1, описание.
2. Фильтры (desktop — сайдбар, mobile — drawer).
3. Активные фильтры и сброс.
4. Список карточек.
5. Пагинация.
6. Пустое состояние.

### Sveden

1. H1.
2. Боковая навигация по подразделам.
3. Обязательные таблицы/поля.
4. Документы.
5. Microdata без визуальных изменений.

## 7. Контент-стиль

- Заголовки — с заглавной буквы, без CAPS LOCK.
- Названия документов — по шаблону: «Правила приёма на 2026 год».
- Даты — «19 октября 2026 г.».
- Телефоны — `+7 (8617) 76-78-00`.
- Ссылки — осмысленный текст.
- Сокращения расшифровывать при первом упоминании.
- Не использовать «актуальная информация» без даты.
- Для устаревших страниц — явная плашка «Архив» и дата.

## 8. Иконки и изображения

- Формат: SVG для иконок, WebP/AVIF для фото.
- Иконки декоративные — `aria-hidden="true"`.
- Фото с людьми — согласие на публикацию.
- Alt: что изображено и зачем, без «изображение».
- Не растягивать логотип, не менять пропорции.

## 9. Тёмная тема, ГОСТ и слабовидящие

- Основная тема — светлая.
- Тёмная тема — опционально, через токены.
- Версия для слабовидящих: крупный шрифт, высокий контраст, отключение фоновых изображений, упрощённая навигация. Реализуется как альтернативная тема, а не отдельный сайт.
- Соответствие ГОСТ Р 52872-2019 и WCAG 2.1 AA.
- Настройки слабовидящих сохраняются в localStorage.
- Проверка: контраст, масштаб 200%, клавиатура, скрытие декоративных изображений.

## 10. Приёмка дизайна

- Все состояния компонентов описаны и реализованы.
- Нет горизонтального скролла на 320px.
- Контраст проверен.
- Фокус видим на всех интерактивных элементах.
- Компоненты совпадают в Figma и коде (если есть макеты).
- Тексты не обрезаются при увеличении шрифта до 200%.
