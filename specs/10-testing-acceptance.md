# 10. Testing and acceptance

## 1. Стратегия

| Уровень | Инструмент | Что проверяем |
|---|---|---|
| Static | `vue-tsc`, ESLint, Prettier | Типы, стиль, ошибки |
| Unit | Vitest | Утилиты, composables, валидация, форматирование |
| Component | Vue Test Utils + Vitest | Компоненты, состояния, события |
| Data validation | Zod + скрипты | JSON, ссылки, медиа, i18n, sveden |
| E2E | Playwright | Пользовательские сценарии, навигация, формы |
| Accessibility | axe-core + Playwright | Критические нарушения |
| Performance | Lighthouse CI | Бюджеты LCP/INP/CLS |
| Visual | Playwright screenshots (опционально) | Регрессии вёрстки |
| Data | Скрипты валидации | Sveden microdata, редиректы, битые ссылки |

## 2. Что тестировать обязательно

### Навигация

- Все 8 разделов открываются.
- Все пункты меню отдают 200.
- Мобильное меню, клавиатура, Escape, focus trap.
- Хлебные крошки.
- Переключатель «слабой видимости».
- Поиск доступен с любой страницы.

### Контент

- Главная, разделы, карточки сущностей.
- Каталог программ с фильтрами.
- Новости, архив, пагинация.
- Документы: скачивание, метаданные.
- Сотрудники, подразделения.
- Журналы и выпуски.
- Контакты, телефонный справочник.
- Sveden: все разделы, microdata.
- 404 и 500.

### Формы (моки)

- Валидация обязательных полей.
- Ошибки полей и общий статус.
- Мок-успех и сообщение «Демо-режим».
- Согласие на ПДн.
- Нет реальных сетевых запросов.

### Поиск

- Pagefind-индекс собран.
- По страницам, новостям, программам, сотрудникам, документам.
- RU и EN.
- Пустой запрос, нет результатов.
- Фильтры и сброс.
- Подсказки.

### SEO

- Title/description/canonical на всех страницах.
- Один h1.
- JSON-LD валиден.
- Sitemap/robots.
- `redirects.json`/`gone.json` сгенерированы и валидны.
- 404/410 статусы на хостинге.
- SSG HTML содержит контент.
- hreflang RU/EN корректен.

### Доступность

- axe: 0 critical/serious.
- ГОСТ Р 52872-2019.
- Клавиатура: все действия.
- Контраст.
- Alt.
- Таблицы.
- Формы.
- Увеличение текста до 200%.
- 320px.
- Версия для слабовидящих: переключение, сохранение, контраст, отключение фонов.

### Производительность

- Lighthouse mobile: Performance ≥ 90.
- LCP ≤ 2.5s, CLS ≤ 0.1, INP ≤ 200ms.
- JS/CSS в бюджете.
- Изображения оптимизированы.

## 3. Тестовые данные

- Staging с копией справочников и 10–20 страниц каждого типа.
- Не использовать реальные персональные данные.
- Тестовые документы и медиа.
- Тестовые редиректы.
- Тестовый sveden с полным набором полей.

## 4. Приёмочные критерии по эпикам

### E1. Информационная архитектура и навигация

- [ ] 8 разделов и служебное меню.
- [ ] Нет 404 в меню.
- [ ] Внешние сервисы вынесены из контентных меню.
- [ ] `sveden` не используется как «Об университете».
- [ ] Хлебные крошки и активные состояния.

### E2. Страницы и контент

- [ ] Все типы шаблонов реализованы.
- [ ] Контент приходит из валидных JSON и отображается без ошибок.
- [ ] Нет неразмеченных битых ссылок.
- [ ] Изображения с alt.
- [ ] Таблицы доступны.

### E3. Поступление

- [ ] Один хаб `/admissions`.
- [ ] Уровни и правила актуальны.
- [ ] Нет страниц 2012/2017 в основном контуре.
- [ ] CTA «Подать документы» ведёт на корректный сервис.
- [ ] FAQ и контакты приёмной комиссии.

### E4. Образование

- [ ] Каталог программ с фильтрами.
- [ ] Карточка программы с документами.
- [ ] Учебный процесс и расписание.
- [ ] Библиотека консолидирована.
- [ ] ДПО и юридическая клиника.

### E5. Наука

- [ ] Направления, лаборатории, НИИ.
- [ ] Аспирантура и диссоветы.
- [ ] Конференции и гранты.
- [ ] Журналы, выпуски, правила.
- [ ] Архив старых лет.

### E6. Студенческая жизнь и новости

- [ ] События, культура, спорт, организации.
- [ ] Общежитие, стипендии, поддержка, ОВЗ.
- [ ] Новости с категориями и архивом.
- [ ] Музей без чужих страниц.
- [ ] Карьера и практика.

### E7. Международное и контакты

- [ ] Иностранным студентам.
- [ ] Партнёры, программы, мобильность.
- [ ] Контакты, телефонный справочник, обратная связь.
- [ ] Карта и режим работы.

### E8. Sveden

- [ ] URL сохранены.
- [ ] Обязательные `itemprop`/`itemtype` присутствуют.
- [ ] Все обязательные разделы и поля.
- [ ] Валидатор проходит.
- [ ] Согласование и аудит.

### E9. SEO и миграция

- [ ] Sitemap/robots.
- [ ] Canonical/meta/OG.
- [ ] 301 для старых URL.
- [ ] Нет цепочек редиректов.
- [ ] 404-мониторинг.
- [ ] Search Console/Вебмастер.

### E10. Контент и данные

- [ ] Все JSON проходят Zod.
- [ ] Нет битых внутренних ссылок.
- [ ] Медиа существуют, alt заполнен.
- [ ] RU/EN-пары согласованы.
- [ ] Sveden microdata валидны.
- [ ] Pagefind-индекс собран.
- [ ] `redirects.json`/`gone.json` валидны.

### E11. Качество

- [ ] axe без critical/serious.
- [ ] Lighthouse mobile ≥ 90.
- [ ] Бюджеты JS/CSS.
- [ ] Тесты проходят в CI.
- [ ] Нет `any` без обоснования.
- [ ] Код-ревью.

## 5. Definition of Done

Задача считается выполненной, если:

1. Реализована функциональность и состояния.
2. Написаны/обновлены тесты.
3. Пройдены typecheck, lint, unit, e2e, axe.
4. Обновлены спецификации/документация.
5. Проверены мобильный вид и клавиатура.
6. Нет новых 404 и ошибок в консоли.
7. Код прошёл ревью.
8. Изменения задеплоены на staging и проверены.

## 6. Окружения

| Окружение | Назначение |
|---|---|
| local | Разработка, mock JSON |
| test | CI, unit/component |
| staging | Полная копия, приёмка, миграция |
| production | Боевой сайт |

## 7. Нефункциональные критерии

- Время ответа статики с Nginx p95 ≤ 300 мс.
- Доступность 99.9% в месяц (зона инфраструктуры).
- Восстановление — предыдущая статическая сборка.
- Уязвимости: нет critical/high в зависимостях на релизе.
- Сборка воспроизводима; версия Node фиксирована.
