# 01. Information architecture

## 1. Принципы

1. Навигация строится вокруг задач аудиторий, а не вокруг отделов и старых меню.
2. В основном меню 8 разделов; вложенность — не глубже 2 уровней.
3. Одна сущность — одна каноническая страница. Факультет, кафедра, программа, сотрудник и новость не дублируются в разных разделах.
4. Внешние сервисы (ЛК, портал, оплата, расписание) живут в служебной шапке, а не в контентных меню.
5. Обязательный `sveden` не смешивается с «Об университете».
6. Старое и архивное не попадает в основное меню.
7. Поиск доступен с любой страницы.

## 2. Основная навигация

| # | Раздел | URL | Назначение |
|---|---|---|---|
| 1 | Университет | `/about` | О вузе, структура, руководство, сотрудники, документы, музей |
| 2 | Поступление | `/admissions` | Все уровни, правила, сроки, стоимость, FAQ, подача документов |
| 3 | Образование | `/education` | Программы, учебный процесс, библиотека, ДПО |
| 4 | Наука | `/science` | Направления, лаборатории, диссоветы, конференции, журналы |
| 5 | Студенческая жизнь | `/student-life` | События, культура, спорт, общежитие, поддержка, карьера |
| 6 | Международное сотрудничество | `/international` | Иностранным студентам, партнёры, программы, мобильность |
| 7 | Новости | `/news` | Лента, категории, архив |
| 8 | Контакты | `/contacts` | Приёмная комиссия, телефонный справочник, обратная связь |

Служебный контур (шапка/футер):

- Сведения об образовательной организации — `/sveden`.
- Версия для слабовидящих.
- Переключатель RU/EN.
- Поиск — `/search` (Pagefind).
- Карта сайта — `/sitemap`.
- Политика обработки персональных данных, cookies.
- Внутренние сервисы: ЛК абитуриента, ЛК студента, образовательный портал, расписание, оплата, библиотека, почта.

Быстрые входы по аудиториям:

- Абитуриенту → `/admissions`.
- Студенту → `/student-life` + быстрые сервисы.
- Сотруднику → `/about/employees` + внутренние сервисы.
- Выпускнику → `/student-life/career` + новости/ассоциация.

### 3.9 Английская версия — `/en/*`

Полное зеркало основных разделов:

```
/en
/en/about
/en/admissions
/en/education
/en/science
/en/student-life
/en/international
/en/news
/en/contacts
```

Правила:

- RU — основной язык, EN — полное зеркало.
- Переключатель языка сохраняет текущую страницу, если перевод есть; иначе ведёт на раздел.
- `hreflang` для RU/EN, `x-default` — RU.
- Непереведённые страницы не публикуются в EN-навигации.
- Slug в EN — латиница; может отличаться от RU.

## 4. Шаблоны страниц

| Шаблон | Где используется | Обязательные блоки |
|---|---|---|
| Home | `/` | Hero, быстрые входы, новости, ключевые цифры, программы, события, контакты |
| Section landing | `/about`, `/admissions`, `/education`, `/science`, `/student-life`, `/international`, `/contacts` | H1, краткое описание, карточки подразделов, быстрые ссылки |
| Catalog | `/education/programs`, `/news`, `/science/conferences`, `/about/employees` | H1, фильтры, список, пагинация, пустое состояние |
| Entity detail | факультет, кафедра, программа, сотрудник, журнал, событие | H1, метаданные, контент, связи, контакты, документы |
| Article | новость, статья, страница | H1, дата, автор, обложка, контент, связанные материалы |
| Document list | `/about/documents`, sveden | H1, категории, поиск/фильтр, таблица/список, метаданные |
| Contact | `/contacts/*` | Контакты, карта, режим работы, форма, ответственные |
| Sveden | `/sveden/*` | Обязательные таблицы, microdata, навигация по подразделам |
| Search | `/search` | Запрос, фильтры, результаты по типам, пустое состояние |
| Error | 404/500 | Пояснение, поиск, популярные ссылки, контакты |
| Archive | `/archive/*`, `/news/archive` | Список, год/категория, `noindex` |

## 5. Навигационные правила

1. В шапке — логотип, 8 разделов, поиск, быстрые сервисы, версия для слабовидящих.
2. В подвале — `sveden`, документы, контакты, карта сайта, политика, соцсети, внутренние сервисы.
3. Хлебные крошки на всех страницах, кроме главной.
4. Активный раздел подсвечивается; на мобильных — drawer-меню с теми же 8 разделами.
5. Внешние ссылки помечаются иконкой и открываются по возможности в новой вкладке.
6. Не использовать выпадающие меню с 7+ пунктами; лучше landing-страница раздела.
7. Не выводить в меню архивные годы, старые стоимости и внутренние документы.
8. Все пункты меню должны вести на 200, а не на 404.

## 6. Поиск и фильтры

- Глобальный поиск: страницы, новости, программы, сотрудники, документы, события.
- Реализация: Pagefind по статическому индексу, собранному после SSG.
- Фильтры каталога программ: уровень, факультет/институт, форма обучения, язык, бюджет/платно.
- Фильтры новостей: год, категория, тег.
- Фильтры документов: раздел, тип, год.
- URL фильтров — query-параметры (`?level=bachelor&faculty=...`), канонический URL без фильтров, `noindex` для комбинаций.
- Пустые состояния с подсказками и ссылками.
